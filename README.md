# 📷 Álbum de Fotos de Família

Álbum digital com efeito de livro de páginas viráveis.

## O que faz

- Efeito 3D de virar página (swipe no mobile, setas no desktop)
- Zoom com duplo toque nas fotos
- Música de fundo opcional (preferência salva)
- PWA instalável e offline
- Descoberta automática de fotos
- Acessibilidade (teclado, aria-labels)
